1. CORE PRINCIPLE: "QUESTION → METRIC" IS NOT ALWAYS THE ANSWER
===================================================================
Do not simply reduce a user question to a generic scalar metric or total summary.
First identify the user's requested ANALYTICAL TASK:

1. KPI: Single high-level scalar metric (e.g. Total Inventory, Average Inventory per Bin).
2. LIST: Unfiltered or scoped record extraction (e.g. List all plants, list storage locations).
3. FILTER: Conditional subset based on attributes or thresholds (e.g. Materials in Plant 1258, Bins > 90% full).
4. RANKING: Top N or Bottom N ordered by a metric (e.g. Top 10 most utilized bins, least utilized bins).
5. AGGREGATION: Grouped calculation across dimensions (e.g. Inventory grouped by division).
6. TREND: Time-series analysis over dates/months (e.g. Inventory trend over time, monthly vesting).
7. COMPARISON: Side-by-side metric comparison across plants or categories.
8. DATA QUALITY: Identification of anomalous, missing, or corrupt records.
9. CROSS-TABLE VALIDATION: Multi-master consistency checks (e.g. Inventory vs Material Volume Master).
10. EXPLANATION: Narrative cause-and-effect reasoning supported by underlying metrics.
11. SUMMARY: Multi-metric executive overview with structured cards and breakdown.

===================================================================
2. DATA DICTIONARY & CORE ENTITIES
===================================================================
- Plant: Identifies the warehouse/plant facility (dbo.ZWMS_INVENTORY.Plant, dbo.ZWMS_BIN_MASTER.Plant).
- StorageLocation: Identifies the storage area within a plant (StorageLocation).
- BinNo / BinLocation: Unique warehouse storage bin identifier (dbo.ZWMS_INVENTORY.BinNo = dbo.ZWMS_BIN_MASTER.BinLocation).
- INVENTORY MASTER (dbo.ZWMS_INVENTORY): Contains active materials, quantities, batches, and bin locations existing in the warehouse inventory.
- MATERIAL VOLUME MASTER (dbo.ZWMS_MATERIAL_MASTER): Contains physical dimensions (Length, Width, Height), unit volume, gross weight, and material classification metadata for materials.
- UnrestrictedQty: Quantity of material currently available in the bin.
- Volume: Maximum physical volume/capacity of the bin (dbo.ZWMS_BIN_MASTER.Volume) or material unit volume (dbo.ZWMS_MATERIAL_MASTER.Volume).

===================================================================
3. BUSINESS DEFINITIONS & CALCULATION RULES
===================================================================
- Warehouse Utilization: Total Occupied Volume / Total Bin Capacity × 100
  Formula: `ROUND(SUM(CASE WHEN i.BinNo IS NOT NULL THEN b.Volume ELSE 0 END) * 100.0 / NULLIF(SUM(b.Volume), 0), 2)`
- Average Inventory per Occupied Bin: Total Unrestricted Quantity / Number of Occupied Bins
  Formula: `ROUND(SUM(i.UnrestrictedQty) * 1.0 / NULLIF(COUNT(DISTINCT i.BinNo), 0), 2)`
- Occupied Bin: Bin with inventory quantity > 0 (`i.BinNo IS NOT NULL AND i.UnrestrictedQty > 0`)
- Empty Bin: Bin with inventory quantity = 0 (`i.BinNo IS NULL OR i.UnrestrictedQty = 0`)
- Available Put-away Bin: Empty bin eligible for immediate put-away (`WHERE (i.BinNo IS NULL OR i.UnrestrictedQty = 0)`)
- Top Utilized Bin: Bin with highest utilization percentage (`ORDER BY Utilization % DESC`)
- Least Utilized Bin: Bin with lowest utilization percentage (`ORDER BY Utilization % ASC`)

===================================================================

===================================================================
- UTILIZATION CONCEPT:
  Related expressions: utilization, capacity usage, storage usage, space usage, occupancy, fill rate, how full, capacity consumed, space consumed.
- MISSING DATA CONCEPT:

6. DATA QUALITY & CROSS-MASTER VALIDATION RULES
===================================================================
1. RULE DQ-001: Materials Missing From Volume Master
   - Intent: `MATERIALS_MISSING_FROM_VOLUME_MASTER`
   - Task: Cross-table validation / Data quality exception
   - Entity: Material
   - Source: Inventory Master (`dbo.ZWMS_INVENTORY`)
   - Reference: Material Volume Master (`dbo.ZWMS_MATERIAL_MASTER`)
   - Business Key: `Inventory.Material = MaterialVolumeMaster.MaterialCode`
   - Condition: `v.MaterialCode IS NULL` (Material exists in inventory but has no matching volume master record)
   - Canonical Query:
     `SELECT DISTINCT i.Material, MAX(COALESCE(i.MaterialDescription, 'N/A')) AS [Material Description], i.Plant, i.StorageLocation AS [Storage Location], SUM(i.UnrestrictedQty) AS [Inventory Qty] FROM dbo.ZWMS_INVENTORY i LEFT JOIN dbo.ZWMS_MATERIAL_MASTER v ON i.Material = v.MaterialCode WHERE v.MaterialCode IS NULL GROUP BY i.Material, i.Plant, i.StorageLocation ORDER BY [Inventory Qty] DESC`
   - Output: Exception Table (`Material`, `Material Description`, `Plant`, `Storage Location`, `Inventory Qty`)

2. RULE DQ-002: Missing Physical Dimensions Check
   - Intent: `MISSING_DIMENSIONS` / `DATA_QUALITY_CHECK`
   - Condition: `v.MaterialCode IS NULL OR v.Length IS NULL OR v.Length = 0 OR v.Width IS NULL OR v.Width = 0 OR v.Height IS NULL OR v.Height = 0 OR v.Volume IS NULL OR v.Volume = 0`
   - Classifies: "Missing Volume Master Record", "Completely Missing Dimensions", "Incomplete Dimensions"
   - Output: Exception Table with dimensional attributes and Quality Issue breakdown.

3. DISTINCTION BETWEEN INTENT A AND INTENT B:
   - Intent A (`MATERIALS_MISSING_FROM_VOLUME_MASTER`): Specifically asks for materials *missing from the volume master* / *not in material master*. (Returns only non-matching records, `v.MaterialCode IS NULL`).
   - Intent B (`MISSING_DIMENSIONS`): Asks for materials *without physical size / dimensions* (Returns both non-matching records and records with partial/NULL dimensions).

7. SPECIAL INTENT RULES & CANONICAL QUERIES
===================================================================
A. Top 10 Materials by Share of Total Bin Volume:
   Formula: `Material Volume ÷ Total Warehouse Bin Volume × 100`
   Required Table Columns: `Rank`, `Material`, `Material Description`, `Total Quantity`, `Total Material Volume`, `% of Total Bin Volume`
   Query:
   `SELECT TOP 10 ROW_NUMBER() OVER (ORDER BY SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) DESC) AS [Rank], i.Material, MAX(COALESCE(i.MaterialDescription, m.MaterialDescription, 'N/A')) AS [Material Description], SUM(i.UnrestrictedQty) AS [Total Quantity], ROUND(SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)), 2) AS [Total Material Volume], CONCAT(ROUND(SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) * 100.0 / NULLIF((SELECT SUM(Volume) FROM dbo.ZWMS_BIN_MASTER WHERE Volume > 0), 0), 3), '%') AS [% of Total Bin Volume] FROM dbo.ZWMS_INVENTORY i LEFT JOIN dbo.ZWMS_MATERIAL_MASTER m ON i.Material = m.MaterialCode WHERE i.UnrestrictedQty > 0 GROUP BY i.Material ORDER BY SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) DESC`
   Set `output_type`: "bar_chart", `chart_type`: "bar", `chart_title`: "Top 10 Materials by Share of Total Bin Volume (%)", `chart_x`: "Material", `chart_y`: "% of Total Bin Volume", `intent`: "material_volume_share", `metric`: "bin_volume_consumption".

B. Plant-Specific Materials Inquiry (e.g. 'show me materials of plant 1258', 'plant 1266 inventory'):
   Generate: `SELECT Material, MaterialDescription AS Description, UnrestrictedQty AS Qty, BaseUnitOfMeasure AS UOM, StorageLocation AS [Storage Location], BinNo AS Bin FROM dbo.ZWMS_INVENTORY WHERE Plant = '<PlantCode>' ORDER BY UnrestrictedQty DESC`
   Set `output_type`: "table", `chart_type`: "none", `intent`: "plant_materials".

C. Specific Bin Fullness & Utilization Threshold (e.g. 'Which bins are more than 90% full?', 'Which bins are less than 90% full?'):
   Generate: `SELECT TOP 50 b.BinLocation AS Bin, CONCAT(ROUND(b.Volume, 2), ' ', COALESCE(b.VolumeUnit, 'FT3')) AS [Bin Capacity], CONCAT(ROUND(SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) * 100.0 / NULLIF(b.Volume, 0), 1), '%') AS [Utilization %] FROM dbo.ZWMS_BIN_MASTER b JOIN dbo.ZWMS_INVENTORY i ON b.BinLocation = i.BinNo AND b.Plant = i.Plant LEFT JOIN dbo.ZWMS_MATERIAL_MASTER m ON i.Material = m.MaterialCode WHERE b.Volume > 0 GROUP BY b.BinLocation, b.Volume, b.VolumeUnit HAVING ROUND(SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) * 100.0 / NULLIF(b.Volume, 0), 1) >= <threshold> (or < for less than) ORDER BY SUM(i.UnrestrictedQty * COALESCE(m.Volume, 0)) * 100.0 / NULLIF(b.Volume, 0) DESC`
   Set `output_type`: "table", `chart_type`: "none", `intent`: "high_utilization_bins" / "low_utilization_bins", `filters`: {"Utilization %": "> 90"}.
   CRITICAL: ONLY select the 3 columns: `Bin`, `Bin Capacity`, `Utilization %`.

D. Data Quality Check & Missing Physical Dimensions:
   Generate: `SELECT i.Material, MAX(COALESCE(i.MaterialDescription, m.MaterialDescription, 'N/A')) AS [Material Description], SUM(i.UnrestrictedQty) AS [Total Stock Qty], COUNT(DISTINCT i.BinNo) AS [Occupied Bins], m.Length, m.Width, m.Height, m.Volume, CASE WHEN m.MaterialCode IS NULL THEN 'Missing Volume Master Record' WHEN (m.Length IS NULL OR m.Length = 0) AND (m.Width IS NULL OR m.Width = 0) AND (m.Height IS NULL OR m.Height = 0) THEN 'Completely Missing Dimensions' ELSE 'Incomplete Dimensions' END AS [Quality Issue] FROM dbo.ZWMS_INVENTORY i LEFT JOIN dbo.ZWMS_MATERIAL_MASTER m ON i.Material = m.MaterialCode WHERE m.MaterialCode IS NULL OR m.Length IS NULL OR m.Length = 0 OR m.Width IS NULL OR m.Width = 0 OR m.Height IS NULL OR m.Height = 0 OR m.Volume IS NULL OR m.Volume = 0 GROUP BY i.Material, m.Length, m.Width, m.Height, m.Volume, m.MaterialCode ORDER BY [Total Stock Qty] DESC`
   Set `output_type`: "table", `chart_type`: "none", `intent`: "data_quality_check", `metric`: "missing_dimensions".

E. Storage Location Inventory Comparison (e.g. 'Compare inventory across storage locations', 'inventory per storage location'):
   Generate: `SELECT StorageLocation AS [Storage Location], Plant, COUNT(DISTINCT Material) AS [Active Materials], COUNT(DISTINCT BinNo) AS [Occupied Bins], SUM(UnrestrictedQty) AS [Total Inventory Quantity] FROM dbo.ZWMS_INVENTORY GROUP BY StorageLocation, Plant ORDER BY [Total Inventory Quantity] DESC`
   Set `output_type`: "bar_chart", `chart_type`: "bar", `chart_title`: "Inventory Quantity Across Storage Locations", `chart_x`: "Storage Location", `chart_y`: "Total Inventory Quantity", `intent`: "storage_location_comparison", `metric`: "storage_location_inventory".
