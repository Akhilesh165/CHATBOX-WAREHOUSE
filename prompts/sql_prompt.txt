1. CORE PRINCIPLE: "QUESTION → METRIC" IS NOT ALWAYS THE ANSWER
===================================================================
Do not simply reduce a user question to a generic scalar metric or total summary.
First identify the user's requested ANALYTICAL TASK:

1. KPI: Single high-level scalar metric (e.g. Total Inventory, Average Inventory per Bin).
2. LIST: Unfiltered or scoped record extraction (e.g. List all plants, list storage locations).
3. FILTER: Conditional subset based on attributes or thresholds (e.g. Materials in Plant 1258, Bins > 90% full).
4. RANKING: Top N or Bottom N ordered by a metric (e.g. Top 10 most utilized bins, least utilized bins).
5. AGGREGATION: Grouped calculation across dimensions (e.g. Inventory grouped by division).
6. TREND: Time-series analysis over dates/months (e.g. Inventory trend over time, monthly vesting).
7. COMPARISON: Side-by-side metric comparison across plants or categories.
8. DATA QUALITY: Identification of anomalous, missing, or corrupt records.
9. CROSS-TABLE VALIDATION: Multi-master consistency checks (e.g. Inventory vs Material Volume Master).
10. EXPLANATION: Narrative cause-and-effect reasoning supported by underlying metrics.
11. SUMMARY: Multi-metric executive overview with structured cards and breakdown.

===================================================================
2. DATA DICTIONARY & CORE ENTITIES
===================================================================
- Plant: Identifies the warehouse/plant facility (dbo.ZWMS_INVENTORY.Plant, dbo.ZWMS_BIN_MASTER.Plant).
- StorageLocation: Identifies the storage area within a plant (StorageLocation).
- BinNo / BinLocation: Unique warehouse storage bin identifier (dbo.ZWMS_INVENTORY.BinNo = dbo.ZWMS_BIN_MASTER.BinLocation).
- INVENTORY MASTER (dbo.ZWMS_INVENTORY): Contains active materials, quantities, batches, and bin locations existing in the warehouse inventory.
- MATERIAL VOLUME MASTER (dbo.ZWMS_MATERIAL_MASTER): Contains physical dimensions (Length, Width, Height), unit volume, gross weight, and material classification metadata for materials.
- UnrestrictedQty: Quantity of material currently available in the bin.
- Volume: Maximum physical volume/capacity of the bin (dbo.ZWMS_BIN_MASTER.Volume) or material unit volume (dbo.ZWMS_MATERIAL_MASTER.Volume).

===================================================================
3. BUSINESS DEFINITIONS & CALCULATION RULES
===================================================================
- Warehouse Utilization: Total Occupied Volume / Total Bin Capacity × 100
  Formula: `ROUND(SUM(CASE WHEN i.BinNo IS NOT NULL THEN b.Volume ELSE 0 END) * 100.0 / NULLIF(SUM(b.Volume), 0), 2)`
- Average Inventory per Occupied Bin: Total Unrestricted Quantity / Number of Occupied Bins
  Formula: `ROUND(SUM(i.UnrestrictedQty) * 1.0 / NULLIF(COUNT(DISTINCT i.BinNo), 0), 2)`
- Occupied Bin: Bin with inventory quantity > 0 (`i.BinNo IS NOT NULL AND i.UnrestrictedQty > 0`)
- Empty Bin: Bin with inventory quantity = 0 (`i.BinNo IS NULL OR i.UnrestrictedQty = 0`)
- Available Put-away Bin: Empty bin eligible for immediate put-away (`WHERE (i.BinNo IS NULL OR i.UnrestrictedQty = 0)`)
- Top Utilized Bin: Bin with highest utilization percentage (`ORDER BY Utilization % DESC`)
- Least Utilized Bin: Bin with lowest utilization percentage (`ORDER BY Utilization % ASC`)

===================================================================
4. SYNONYMS & CONCEPT ONTOLOGIES
===================================================================
- UTILIZATION CONCEPT:
  Related expressions: utilization, capacity usage, storage usage, space usage, occupancy, fill rate, how full, capacity consumed, space consumed.
- MISSING DATA CONCEPT:
  Related expressions: missing, unavailable, not maintained, not defined, incomplete, blank, NULL, absent, not available, without.
- DIMENSION CONCEPT:
  Related expressions: dimensions, physical dimensions, size, length/width/height, dimensional data, volume information, size information.

6. DATA QUALITY RULES
===================================================================
1. Cross-Master Validation:
   The AI compares records across related master/data tables when the user asks about missing, inconsistent, unmatched, or incomplete information.
2. Material Matching:
   Inventory Master materials must be matched to Material Volume Master using the defined Material ID/Material Number key (`Inventory.Material = MaterialMaster.MaterialCode`).
3. Missing Dimensions:
   A material has incomplete physical dimensions when any required dimension (Length, Width, Height) is blank, 0, or NULL.
4. Missing Master Record:
   If an Inventory Master material has no corresponding record in Material Volume Master, classify it as: "Missing Volume Master Record".
5. Output:
   For data-quality questions, return:
   - Number of affected records
   - Exception table
   - Relevant fields (Material, Material Description, Total Stock Qty, Occupied Bins, Length, Width, Height, Volume, Quality Issue)
   - Explanation of the detected issue
